## 環境
| 項目 | 決定 |
|---|---|
| 遊戲名稱 | 《菸菸一熄》 |
| Unity 版本 | 6000.0.43f1（三人相同） |
| Render Pipeline | **URP**（`com.unity.render-pipelines.universal` 17.0.4，使用 `Assets/Settings/PC_RPAsset`） |
| 畫面後製效果 | 使用 URP 內建的 Volume（`UnityEngine.Rendering` / `UnityEngine.Rendering.Universal`），**不要用** Post Processing v2（`PostProcessVolume`，在 URP 中沒有作用） |
| 輸入系統 | 新版 Input System；程式用 `Keyboard.current` / `Mouse.current` 直接讀取。Player Settings 的 Active Input Handling 設為 **Both**，避免組員 AI 產生的舊版 `Input.GetKey` 程式直接報錯 |
| 攝影機 | 只用一台 Main Camera，切換第一／第三人稱時移動它的位置（小地圖與畫面效果都抓得到同一台） |
| 場景 | 全部內容放在同一個 GameScene；故事地點建在地圖外圍，用淡出傳送切換，**不切換場景** |

## 流程規則
| 項目 | 決定 |
|---|---|
| 倒數計時 | **取消**。只記錄用時（不倒數、不會因時間失敗）；暫停與過場動畫不計時 |
| 勝利 | 打倒 BOSS，淨化進度達 100% |
| 失敗 | **HP 歸零**（任何階段）。沒有倒地、沒有復起 |
| 接受香菸 | 全部是動畫：三位路人（老奶奶、小朋友、爸爸）**隨機出現一位** → 咳嗽 → 台詞 → 動手 → 玩家暈倒 → **重新載入場景，回到開場選擇**。不進結算 |
| 拒絕香菸 | 朋友點菸成為煙霧來源 → 車庫門打開 → 新手教學 |
| 新手教學 | 4 步驟，每一步只能做指定的動作（滑鼠轉視角全程可用）：① 按 V 切換視角 ② WASD 走到車庫外的發光位置 ③ 走到小菸怪旁 ④ 左鍵擊敗它。教學菸怪**不加淨化進度** |
| 第一階段 | 在街上擊敗 5 隻小菸怪（淨化 0 → 20%）→ 第一位 NPC 跑來求救，進入第二階段 |
| 第二階段 | 三個 NPC 事件依序出現；每個事件結束後 **40 秒**下一位 NPC 出現。事件一強制進行；事件二、三跳出「要幫忙嗎？」視窗 |
| NPC 事件流程 | 淡出傳送到故事地點 → 消滅 3 隻菸怪 → 聽故事 → 按 E 互動 → 結局 → NPC 給道具並說明真實用途 → 傳送回街道 |
| 拒絕幫忙 | **整張地圖**的菸怪都無法消除，煙霧範圍逐漸擴大；NPC 跟著玩家，玩家回頭對 NPC 按 E 即可接下任務，接下後恢復原狀 |
| 進入第三階段 | 三個事件完成 → 老奶奶給藏寶圖 → 走到吸菸室旁的寶箱按 E。淨化 **< 60%** 時寶箱鎖住，提示「路上好像還有還沒消除的煙怪」；**≥ 60%** 時取得噴霧 → BOSS 登場動畫 |
| 第三階段 | BOSS 從吸菸室衝上天空、吸菸者散開到街上 → 「第三階段規則介紹視窗」→ 玩家點擊後開始 BOSS 戰 |
| BOSS 與淨化進度 | 淨化進度 = 60% + 40% ×（1 − BOSS 目前血量 ÷ 最大血量） |
| 第一、二階段失敗 | 結算畫面按「重新開始」，回到開場選擇 |
| 第三階段失敗 | 結算畫面多一個「從第三階段重新挑戰」：HP 與道具恢復成**第一次進入第三階段時**的狀態；用時**持續累計**；血量分以**最後一次成功打倒 BOSS 時**的血量計算 |
| 暫停 | Esc 暫停（`Time.timeScale = 0`），選單：繼續遊戲、重新開始、返回主選單 |
| 已刪除 | 420 秒倒數、剩 60 秒顯示菸怪、寶箱是非題、護送 NPC 與無菸公園、收編機制、大型菸怪（一般遊戲中）、戒必適、尼古丁吸入劑、Bupropion |

## 玩家操作
| 按鍵 | 功能 |
|---|---|
| W/A/S/D | 移動（相對於鏡頭方向） |
| 滑鼠移動 | 視角；**角色永遠面向鏡頭水平方向**（第一、第三人稱相同） |
| 空白鍵 | 跳躍 |
| 左 Shift | 奔跑 |
| 滑鼠左鍵 | 近戰攻擊（前方 90 度扇形） |
| 滑鼠滾輪／右鍵 | 切換／使用背包道具 |
| E | 互動：NPC 對話與接任務、故事互動、寶箱、捏熄吸菸者的菸（**全遊戲統一用 E，不使用 Q**） |
| V | 第一／第三人稱切換 |
| Tab | 按住放大小地圖 |
| Esc | 暫停選單 |

## 數值
| 項目 | 值 | 備註 |
|---|---|---|
| HP 最大值 | 100 | |
| 暴露值範圍 | 0–100，不顯示數字 | |
| 煙霧來源 | 小菸怪、開場吸菸的朋友、第三階段吸菸 NPC、BOSS、菸炮落地的煙霧區 | |
| 小菸怪／吸菸 NPC 煙霧半徑 | 4 公尺【可調】 | 1 Unity 單位 = 1 公尺 |
| BOSS 煙霧半徑 | 7 公尺【可調】 | |
| 範圍內上升 | 每秒 10 ×（1 − 距離 ÷ 半徑）【可調】 | 多個來源時取**上升速度最大**的那一個，不加總 |
| 範圍外下降 | 每秒 3【可調】 | |
| 暴露值 ≥ 80 | 顯示警示文字；< 80 消失 | |
| 暴露值 = 100 | 每秒扣 5 HP、咳嗽、移速 −30%【可調】 | |
| 小菸怪行為 | 在出生點附近遊走，**不追擊、不攻擊**；3 下擊敗 | 遊走：出生點半徑 3 公尺、每秒 1 公尺【建議】 |
| 小菸怪數量與進度 | 教學 1 隻（0%）；第一階段 5 隻（各 +4%）；每個事件 3 隻（每個事件共 +10%）；兩段空檔各 2 隻（各 +2.5%） | 總和 60%，必須剛好等於第二階段結束的 60% |
| 拒絕幫忙時煙霧擴大 | 每 10 秒 +10%，最多 2 倍【建議】 | 接下任務後恢復 |
| 事件間隔 | 40 秒【可調】 | |
| 評分 | 總分 = 血量分 × 0.6 + 用時分 × 0.4 | |
| 血量分 | HP ÷ 100 × 100 | |
| 用時分 | 用時 ≤ 8 分鐘得 100；之後每多 30 秒 −10，最低 0；失敗局 0【建議】 | |
| 評級 | S ≥ 90、A ≥ 80、B ≥ 70、C ≥ 60、D < 60；失敗局一律 D | |
| 頭銜 | S 無菸守護者、A 清淨行動派、B 街頭淨化員、C 菸霧見習生、D 還在咳嗽中、失敗 被菸霧吞沒 | 提案，可再改 |

## 道具（全部放在背包，滾輪切換、右鍵使用）
| 道具 | 取得 | 使用限制 | 遊戲效果 |
|---|---|---|---|
| 尼古丁貼片 | 事件一：小男孩給 | **只能在第三階段使用**；一次 | 回復 30 HP（不超過上限）。第三階段前按右鍵顯示「第三階段才能使用」，不消耗 |
| 尼古丁口嚼錠 | 事件二：女孩給 | 一次 | 清除玩家周圍半徑內所有 BOSS 菸圈；半徑 15 公尺【建議】 |

- 第三階段規則介紹視窗只說明遊戲功能、按鍵與攻擊方式，不重複說明真實用途。

## BOSS 戰【建議，最後測試階段再調整】
| 項目 | 值 |
|---|---|
| BOSS 最大血量 | 150 |
| 玩家近戰傷害 | 每下 3 |
| 地面停留 | 8 秒；每 2 秒朝玩家吐 1 個小菸圈，命中扣 8 HP |
| 天上停留 | 12 秒；每 4 秒朝玩家當下位置吐菸炮，直接命中扣 15 HP，落地留下 3 秒煙霧區 |
| 天上外觀 | 血量越少飛得越低、體型越小（每降 25% 一級） |
| 回血 | 地面：每位還在抽菸的 NPC 每秒 +1；天上：每秒 +1，再加每位抽菸 NPC 每秒 +1 |
| 吸菸 NPC | **4 位**：爸爸、北友會兩位朋友、阿公（已確認） |
| 捏熄菸蒂 | 面向 NPC、前方 90 度、2 公尺內按 E 開始 **QTE 連打**：2 秒內連打 E 5 次 |
| QTE 失敗 | 進度歸零，可立刻重試；QTE 期間 BOSS 照常攻擊 |
| 菸全部捏熄後 | BOSS 永久停在地面、不再回血；玩家 3 公尺內時每 3 秒揮擊一次，命中扣 10 HP |
