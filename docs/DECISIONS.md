## 流程規則
| 項目 | 決定 |
|---|---|
| 計時 | 不倒數，只記錄**用時**。暫停選單、過場動畫、傳送淡入淡出、對話、「要幫忙嗎？」視窗、規則介紹視窗期間**不計時**；任何系統都可以用 key 申請「暫停計時」（`GameManager.SetTimerPaused`），不會互相覆蓋 |
| 暫停計時期間 | 暴露值、HP（不扣也不回）、40 秒事件空檔、BOSS 行動一起停；玩家操作鎖住、游標解鎖 |
| 勝利 | 打倒 BOSS → 淨化 100%、停止用時 → 結局動畫 → 勝利結算。結局動畫期間不計時，HP 也不會變 |
| 失敗 | **HP 歸零**（新手教學以外的任何階段）→ 失敗結算。沒有倒地、沒有復起 |
| 接受香菸 | 全部是動畫：三位路人（老奶奶、小朋友、爸爸）**隨機出現一位** → 咳嗽 → 台詞 → 動手 → 玩家暈倒 → **重新載入場景，回到開場選擇**。不進結算 |
| 拒絕香菸 | 朋友點菸成為煙霧來源 → 車庫門打開（B 在門開好時通知開場結束）→ 新手教學 |
| 新手教學 | 4 步驟：① 按 V 切換視角 ② WASD 走到車庫外的發光位置 ③ 走到小菸怪旁 ④ 左鍵擊敗它。每一步只能做指定的動作；**滑鼠轉視角、跳躍、奔跑全程可用；E、道具教學中都鎖住**；教學結束全部解鎖。教學菸怪**淨化值 0** |
| 教學期間的 HP 與用時 | **照算**（讓玩家看到遊戲開始時的樣子）。教學結束、第一階段開始時，**用時、HP、暴露值、淨化進度全部重新計算** |
| 教學期間 HP 歸零 | **不進結算**：HP 補滿、暴露值歸零，玩家留在原地，**從當下那一步繼續** |
| 第一階段 | 在街上擊敗 5 隻小菸怪（淨化 0 → 20%）→ 第一位 NPC 跑來求救，提示「城市中還有很多需要幫助的人，快去看看吧！」，進入第二階段 |
| 第二階段 | 三個 NPC 事件依序出現；每個事件結束後 **40 秒**下一位 NPC 出現（空檔期間街上出現 2 隻菸怪）。事件一強制進行；事件二、三跳出「要幫忙嗎？」視窗 |
| NPC 事件流程 | 淡出傳送到故事地點 → 消滅 3 隻菸怪 → 聽故事 → 按 E 互動（一般互動，不是 QTE）→ 結局 → NPC 給道具並說明真實用途 → 傳送回街道 |
| 拒絕幫忙 | **整張地圖**的菸怪都無法消除，煙霧範圍每 10 秒 +10%（線性，最多 2 倍，只影響菸怪）；NPC 跟著玩家，玩家對 NPC 按 E **會再跳一次「要幫忙嗎？」**（可以再拒絕）；接下後煙霧恢復原狀 |
| 拒絕時的提示 | 不直接告訴玩家要回去，只顯示「煙霧好像越來越濃了……」 |
| 藏寶圖 | 事件三完成時老奶奶給藏寶圖；**不放進背包**（背包只有 3 種道具）；小地圖顯示寶箱、任務提示「到吸菸室旁的寶箱看看」 |
| 寶箱 | 名稱 `TreasureChest`（A）。**拿到藏寶圖之前寶箱不存在**（看不到、碰不到、不能按 E）。按 E：淨化 **< 60%** 提示「路上好像還有還沒消除的煙怪」，不打開；**≥ 60%** 取得噴霧 → BOSS 登場動畫 |
| 第三階段 | BOSS 從吸菸室衝上天空、吸菸者散開到街上 → 「第三階段規則介紹視窗」→ 玩家點擊後開始 BOSS 戰（BOSS 先在天上） |
| BOSS 與淨化進度 | **（A11 新決定，優先於 GDD 4.6、8.1 與 15.1 測試表「淨化進度」那一列）淨化進度不跟 BOSS 血量連動**：進入第三階段時是 60%，整場 BOSS 戰都停在 60%（BOSS 回血也不會下降；菸怪等任何來源都不能改變）；**BOSS 被打倒的那一刻才變成 100%**，觸發勝利流程。戰鬥中的回饋由 BOSS 血條（C12）負責。15.1 的驗收條件改成：「第三階段期間淨化固定 60%，打倒 BOSS 時變 100%，不超過 100%」 |
| 第一、二階段失敗 | 結算畫面按「重新開始」，回到開場選擇 |
| 第三階段失敗 | 結算畫面多一個「從第三階段重新挑戰」：HP 與道具恢復成**第一次進入第三階段時**的狀態（之後再重試也一樣用第一次的）；用時**持續累計**（接著失敗那一刻繼續）；淨化從 60% 開始，教學與三個事件視為完成；**重播 BOSS 登場動畫與規則介紹視窗**；血量分以**最後一次成功打倒 BOSS 時**的血量計算 |
| 第三階段起點與快照（A11） | 「從第三階段重新挑戰」（A19）和「開發者跳到第三階段」（F4）**共用同一個起點流程**：重新載入 GameScene 後直接從第三階段開始。快照在**第一次**進入第三階段時存下（HP、道具），放在 static 的 `Phase3Checkpoint`，重新載入場景後還在；回到主選單、重新開始一整局時清除。開發者沒有真正玩過就跳到第三階段時，用預設快照：HP 100、貼片 1、口嚼錠 1、噴霧 1。介面見 INTERFACES 第 22 節 |
| 新手教學期間 HP 歸零（A11 暫時） | A12 完成前：GameManager 不判定失敗，只印 Log；A12 起由 TutorialManager 補滿、從當下那一步繼續 |
| 暫停 | Esc 暫停（`Time.timeScale = 0`），選單：繼續遊戲、重新開始（回到開場選擇）、返回主選單（回到 MainMenu）。UI 由 C 做；**換場景一律呼叫 GameManager 的方法，B、C 不要自己 LoadScene** |
| 對話 | 對話框用**滑鼠左鍵或空白鍵**翻下一句（E 鍵只有 PlayerInteractor 讀） |

## 道具（全部放在背包，滾輪切換、右鍵使用）
| 道具 | 取得 | 使用限制 | 遊戲效果 |
|---|---|---|---|

| 尼古丁戒菸噴霧 | 藏寶圖寶箱 | **無次數限制**；冷卻 1.5 秒【建議】 | **朝鏡頭中央方向瞬間判定**（不是會飛的子彈），每次對 BOSS 造成 7.5 傷害；**只對 BOSS 有效，對小菸怪無效**（射線穿過小菸怪，不會被它擋住；碰到牆會停）；最遠 30 公尺【暫定】；BOSS 在地面、天上都能用 |

- 第三階段以前使用貼片、口嚼錠：顯示「第三階段才能使用」（A 的 PlayerEffects 自動顯示 Toast），**不消耗**。
- （A13）噴霧冷卻中、操作被鎖（教學、對話、暫停、過場、遊戲結束）時按右鍵：**不跳提示**、不消耗；冷卻由背包 UI 顯示。
- （A13）貼片在**滿血時不能用**：顯示「HP 已經是滿的」，**不消耗**。
- （A13）口嚼錠的 15 公尺是從玩家腳底量的 3D 距離。
- NPC 交付道具時，在對話中說明真實用途（協助吸菸者戒菸），並提醒「實際用藥應經醫療專業人員評估」。
- 第三階段規則介紹視窗只說明遊戲功能、按鍵與攻擊方式，不重複說明真實用途。

## BOSS 戰【建議，最後測試階段再調整】
| 項目 | 值 |
|---|---|
| BOSS 最大血量 | 150 |
| 玩家近戰傷害 | 每下 3（**BOSS 在天上時打不到**） |
| 噴霧傷害 | 每下 7.5（地面、天上都可以） |
| BOSS 戰開始前 | 登場動畫、規則視窗期間（以及之前）BOSS **不攻擊、不受傷、不冒煙** |
| 開場 | 規則視窗關掉後 BOSS 先在天上（**A14 只有地面版：開打直接在地面、不輪替；A16 改成先在天上**） |
| 小菸圈（A14） | **地面、天上都吐同一種菸圈**：每 2 秒 1 個（進入狀態 2 秒後吐第一個），命中扣 8 HP；**朝「發射當下」玩家胸口（腳底 +1 公尺）直線飛，不追蹤**（可以閃避）；速度 6 公尺／秒、存在 4 秒、命中半徑 0.8 公尺【暫定】；撞到牆、地面或超過存在時間就消失；**菸圈本身不是煙霧來源**；**口嚼錠不能清除菸圈**；BOSS 在地面時會水平轉向玩家（轉向速度每秒 360 度【可調】）；不用物件池 |
| 地面停留 | 8 秒；從地面 BOSS 的高度（發射點離地 2 公尺）吐菸圈 |
| 天上停留 | 12 秒；從天上 BOSS 的高度吐同一種菸圈（8 HP、每 2 秒、直線朝玩家胸口，沒有落點預警）；**沒打中、落到地面時留下 3 秒煙霧區**（半徑 3 公尺【暫定】，是煙霧來源、可被口嚼錠清除）（A14 決定，A16 實作） |
| 天上外觀 | 血量越少飛得越低、體型越小（每降 25% 一級；高度 12／10／8／6 公尺【暫定】） |
| 回血 | 地面：每位還在抽菸的 NPC 每秒 +1；天上：每秒 +1，再加每位抽菸 NPC 每秒 +1 |
| 吸菸 NPC | **4 位**：爸爸、北友會兩位朋友、阿公（已確認）；和第二階段故事裡的 NPC 是不同物件 |
| 捏熄菸蒂 | 面向 NPC、前方 90 度、2 公尺內按 E 開始 **QTE 連打**：2 秒內連打 E 5 次（**第一下就算 1 下**）。QTE 期間 E 鍵只會交給這位 NPC，不會切換到其他互動目標（A13） |
| QTE 期間 | 玩家不能移動、可以轉視角；被 BOSS 打中**不中斷**；BOSS 照常攻擊 |
| QTE 失敗 | 超過時間才算失敗：進度歸零，可立刻重試 |
