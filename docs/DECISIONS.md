# DECISIONS.md — 團隊已拍板的規則與數值

> 這份檔案優先於企劃書。企劃書內有矛盾時，以這裡為準。
> 標註【可調】的數值必須做成 Inspector 參數，之後測試時再調整。
> 最後更新：2026-11-15（A 整理）

## 環境
| 項目 | 決定 |
|---|---|
| Unity 版本 | 6000.0.43f1（三人相同） |
| Render Pipeline | **URP**（`com.unity.render-pipelines.universal` 17.0.4，使用 `Assets/Settings/PC_RPAsset`） |
| 畫面後製效果 | 使用 URP 內建的 Volume（`UnityEngine.Rendering` / `UnityEngine.Rendering.Universal`），**不要用** Post Processing v2（`PostProcessVolume`，在 URP 中沒有作用） |
| 輸入系統 | 新版 Input System；程式用 `Keyboard.current` / `Mouse.current` 直接讀取。Player Settings 的 Active Input Handling 設為 **Both**，避免組員 AI 產生的舊版 `Input.GetKey` 程式直接報錯 |
| 攝影機 | 只用一台 Main Camera，切換第一／第三人稱時移動它的位置（小地圖與畫面效果都抓得到同一台） |

## 流程規則
| 項目 | 決定 | 企劃書出處 |
|---|---|---|
| HP 歸零 | **立即失敗**，進入失敗結算。**沒有倒地、沒有扣時、沒有復起** | 4.4（取代 10.3、14.1、附錄 A 的倒地規則） |
| 路線 A（接受香菸） | 演出結束後玩家死亡 → **重新載入場景，回到死巷重新選擇**。不進結算、不導回路線 B | 3.2（取代 14.1、16.1） |
| 路線 B（拒絕香菸） | NPC 點菸成為煙霧來源 → 死巷內引導 → **玩家走出死巷時才開始 420 秒倒數** | 3.3、4.1 |
| 暫停 | Esc 可暫停，**暫停時停止計時**（`Time.timeScale = 0`） | 4.2 |
| 勝利 | 淨化進度達 100% | 9.2 |
| 失敗 | 倒數歸零且進度 < 100%，或 HP 歸零 | 9.2 |

## 玩家操作
| 按鍵 | 功能 |
|---|---|
| W/A/S/D | 移動（相對於鏡頭方向） |
| 滑鼠移動 | 視角；**角色永遠面向鏡頭水平方向**（第一、第三人稱相同） |
| 空白鍵 | 跳躍（新增） |
| 左 Shift | 奔跑（新增） |
| 滑鼠左鍵 | 近戰攻擊 |
| 滑鼠滾輪／右鍵 | 切換／使用衛教道具 |
| E | 互動（寶箱、護送 NPC） |
| V | 第一／第三人稱切換 |
| Esc | 暫停選單 |
