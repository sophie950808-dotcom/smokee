## 一、專案概述

### 1.1 專案基本資料

| 預計發表 | 2026/12/24 |

### 1.2 製作動機

二手菸不只影響吸菸者本人，也會使周遭的人在非自願的情況下暴露於菸霧。本遊戲希望透過玩家的選擇、被迫吸菸者的故事與遊戲中的因果回饋，讓玩家看見吸菸行為如何影響旁人。

遊戲刻意把「該改變的人」放在吸菸者身上：故事中的吸菸者最後都選擇走到吸菸區或換地方抽，不再讓家人與朋友吸到二手菸。

### 1.3 專案目標

- 以可操作的 3D 遊戲呈現二手菸來源、暴露與他人受害的關係。
- 透過開場選擇，讓玩家體驗吸菸對旁人的影響，以及拒絕香菸後面對二手菸環境的處境。
- 透過三段 NPC 故事，呈現家人、朋友、伴侶被迫吸菸的處境，並由吸菸者自己做出改變。
- 以 BOSS 戰作為高潮，讓「捏熄菸蒂、斷絕菸源」成為打倒大煙怪的關鍵。
- 以三人可負荷的規模完成可遊玩版本，並在期末發表時穩定展示。

## 二、核心概念與遊戲體驗

### 2.1 核心概念

玩家在死巷中面臨是否接受朋友遞菸的選擇。接受的玩家會因路人吸到二手菸而被教訓，然後回到選擇的地方重新選擇；拒絕的玩家進入新手教學與正式遊戲。

正式遊戲分為三個階段：第一階段打菸怪暖身；第二階段幫助三位被迫吸菸的 NPC，聽他們的故事並說服身邊的吸菸者；第三階段對抗由剩下的二手菸匯聚而成的 BOSS 大煙怪。淨化進度在第二階段結束時達到 60%，打倒 BOSS 後達到 100%。全程沒有倒數計時，HP 歸零才會失敗。

### 2.2 核心遊戲循環（Core Loop）

1. 主選單：開始遊戲、設定、衛教資訊頁。

2. 死巷開場：朋友遞菸，玩家選擇接受或拒絕。

3. 接受：隨機一位路人教訓玩家 → 玩家暈倒 → 回到選擇畫面。

4. 拒絕：朋友自己點菸 → 新手教學（視角、移動、靠近菸怪、攻擊）。

5. 第一階段：在街上打 5 隻小菸怪（淨化 0 → 20%）。

6. 第二階段：三個 NPC 事件依序出現，玩家跟著 NPC 傳送到故事地點、清除菸怪、聽故事、按 E 互動，取得道具（淨化 20 → 60%）。

7. 第三階段：BOSS 大煙怪從吸菸室出現；玩家捏熄街上吸菸者的菸、閃避攻擊、使用道具，打倒 BOSS（淨化 60 → 100%）。

8. 結算：依剩餘血量與用時給出分數、等第與頭銜。

### 2.3 設計原則

- 因果清楚：讓玩家看見煙霧來源、受影響的人，以及菸源被切斷後的變化。
- 吸菸者改變：故事結局由吸菸者自己移動到吸菸區或換地方抽，受害者不需要離開。
- 操作簡單：操作集中在移動、視角、攻擊、E 鍵互動與背包道具。
- 沉浸式回饋：暴露程度以畫面效果呈現，不顯示數值。
- 可完成優先：先確保完整遊戲流程，再增加演出與視覺細節。

## 三、開場雙路線與新手教學

### 3.1 開場情境

遊戲開場在死巷中的車庫內。朋友 NPC 遞菸給玩家，畫面跳出「接受／拒絕」選擇。死巷空間封閉、出入口單一，方便控制鏡頭與 NPC 位置，讓開場事件穩定重現。

### 3.2 路線 A：接受香菸

全部為動畫，玩家不能操作。

1. 玩家接受香菸，角色吸菸，周圍出現煙霧。

2. 系統從下列三位路人中隨機選出一位登場（每次只會出現一位）。

3. 路人吸到二手菸後咳嗽，說出台詞（對話框），然後動手教訓玩家。

4. 動畫結束，玩家暈倒，畫面轉黑，直接回到選擇畫面重新選擇。

| 路人 | 動手方式 | 台詞 |
|---|---|---|
| 老奶奶 | 拿拐杖打 | 「肖年欸！年紀輕輕就抽菸是想看我提早死翹翹嗎！」 |
| 小朋友 | 拿棒棒糖丟 | 「你好臭！你好臭！」 |
| 爸爸 | 抓包後拿衣架打 | 「兒子阿！你怎麼在抽菸！看我不打死你！」 |

※ 演出以誇張、卡通化的方式呈現，重點是「你的菸會影響身邊的人」，避免讓人解讀為鼓勵以暴力回應吸菸者。

### 3.3 路線 B：拒絕香菸

1. 玩家拒絕香菸，朋友自己點菸，成為死巷內第一個煙霧來源。

2. 車庫門打開，畫面提示玩家走出車庫，進入新手教學。

### 3.4 新手教學

每一步只能做該步驟指定的動作；還沒教到的操作沒有作用（滑鼠轉動視角除外，全程可用）。教學用的菸怪不加淨化進度。

| 步驟 | 提示 | 完成條件 |
|---|---|---|
| 1 | 按 V 鍵切換視角 | 切換一次視角 |
| 2 | 試著按 WASD 走走看看吧！（目標位置發光） | 抵達車庫外的發光位置 |
| 3 | 試著走到小煙怪旁邊！（目標位置發光） | 進入教學菸怪旁的範圍 |
| 4 | 按下左鍵消滅菸怪！（菸怪發光提示） | 擊敗教學菸怪 |

完成後顯示「消滅所有的煙怪吧！」，正式進入第一階段，並開始記錄用時。

### 3.5 路線共用與差異

| 項目 | 接受香菸 | 拒絕香菸 |
|---|---|---|
| 開場 | 隨機一位路人吸到二手菸後教訓玩家 | 朋友自己點菸，成為煙霧來源 |
| 主要呈現 | 吸菸行為對旁人的影響與後果 | 非吸菸者被迫暴露於二手菸 |
| 開場結束後 | 玩家暈倒，回到選擇畫面 | 進入新手教學與第一階段 |

※ RouteManager 只記錄玩家的選擇並觸發對應演出，不維護兩套遊戲規則。

## 四、核心玩法與操作規格

### 4.1 遊戲目標

本版取消 420 秒倒數。玩家的目標是依序完成三個階段，最後打倒 BOSS 讓淨化進度達到 100%。唯一的失敗條件是 HP 歸零。遊戲會記錄用時（從第一階段開始，不倒數），作為結算評分的一部分。

### 4.2 玩家操作

| 操作 | 功能 |
|---|---|
| W / A / S / D | 角色移動（相對於鏡頭方向） |
| 滑鼠移動 | 控制視角；角色永遠面向鏡頭水平方向 |
| 空白鍵 | 跳躍 |
| 左 Shift | 奔跑 |
| 滑鼠左鍵 | 近戰攻擊 |
| 滑鼠滾輪 | 切換背包中選取的道具 |
| 滑鼠右鍵 | 使用目前選取的道具 |
| E | 互動：與 NPC 對話、故事互動、捏熄吸菸者的菸（全遊戲統一用 E） |
| V | 第一人稱／第三人稱切換 |
| Esc | 暫停選單（繼續遊戲、重新開始、返回主選單）；暫停時停止計時 |

### 4.3 第一／第三人稱切換

使用同一個角色控制器與同一套移動、攻擊、碰撞邏輯，只移動唯一一台 Main Camera 的位置。

### 4.4 玩家生命值

| 項目 | 規格 |
|---|---|
| HP 最大值 | 100 |
| 扣血來源 | 暴露值達 100（每秒 −5）；BOSS 的菸圈、菸炮與物理攻擊（見第八章） |
| 回血方式 | 尼古丁貼片（第三階段才能使用，+30 HP） |
| HP 歸零 | 立即失敗，進入失敗結算；沒有倒地、沒有復起 |

### 4.5 暴露值（畫面效果）

暴露值範圍 0–100，不顯示數值，以畫面效果呈現：暴露值上升時畫面出現暗角並逐漸變灰；達 80 顯示警示文字；達 100 開始扣血。

| 項目 | 規格 |
|---|---|
| 煙霧來源 | 小菸怪、BOSS、開場吸菸的朋友、第三階段街上的吸菸 NPC |
| 影響範圍 | 小菸怪與吸菸 NPC 半徑 4 公尺；BOSS 半徑 7 公尺【可調】（1 Unity 單位 = 1 公尺） |
| 範圍內上升 | 每秒 10 ×（1 − 距離 ÷ 半徑）【可調】 |
| 多個來源 | 取上升速度最大的來源，不加總 |
| 範圍外下降 | 每秒 3【可調】 |
| 畫面效果 | URP Volume 暗角、降低飽和度；強度與暴露值成正比，保留畫面中央可視 |
| 警示文字 | 暴露值 ≥ 80 時於畫面中上方顯示，< 80 消失 |
| 暴露值 100 | 每秒扣 5 HP，咳嗽並移動速度降低 30%【可調】 |

### 4.6 淨化進度

淨化進度 0–100%，依階段累積（詳見 6.1）。第一、二階段由擊敗菸怪取得；第二階段結束時剛好是 60%；第三階段的 40% 隨 BOSS 血量下降而增加，BOSS 被打倒時達到 100%。新手教學的菸怪不計入。

## 五、角色、菸怪與戰鬥系統

### 5.1 玩家角色

玩家共用生命值、暴露值、近戰攻擊、背包道具與視角切換系統；開場選擇不影響後續能力。

### 5.2 一般菸怪

一般遊戲過程只使用小型菸怪；第三階段的 BOSS 另見第八章。地圖上只放下表的固定菸怪，不另外配置其他怪物。

| 出現時機 | 數量 | 需打擊次數 | 每隻淨化進度 |
|---|---|---|---|
| 新手教學 | 1 隻 | 3 下 | 0%（不計） |
| 第一階段（街道） | 5 隻 | 3 下 | +4%（共 20%） |
| 事件 1、2、3 的故事地點 | 各 3 隻，共 9 隻 | 3 下 | 每個事件共 +10%（共 30%） |
| 事件之間的 40 秒空檔（街道） | 兩段各 2 隻，共 4 隻 | 3 下 | +2.5%（共 10%） |

※ 數量與進度為【建議初始值】，總和必須是 60%，才能和「第二階段結束 = 60%」一致。

※ 兩段 40 秒空檔的 4 隻菸怪沒有清完，淨化就不會達到 60%，第三階段的寶箱會鎖住，並提示「路上好像還有還沒消除的煙怪」（程式只檢查淨化是否 ≥ 60%）。

### 5.3 菸怪行為

| 狀態 | 說明 |
|---|---|
| Idle（散發煙霧） | 在配置位置附近緩慢移動，播放煙霧粒子，作為暴露值的煙霧來源；不追擊、不攻擊。【建議】以出生點為中心、半徑 3 公尺內隨機遊走，速度每秒 1 公尺 |
| Hit（受擊） | 被玩家擊中時播放受擊回饋，累計受擊次數 |
| Dead（消散） | 受擊次數達到門檻後消散、停止散發煙霧，通知 GameManager 增加淨化進度 |
| 無法消除 | 玩家拒絕幫助 NPC 時，整張地圖的菸怪暫時打不掉，煙霧範圍逐漸擴大（見 6.3） |

### 5.4 戰鬥規則

- 普通攻擊為近距離揮擊，判定範圍為玩家前方 90 度扇形。
- 每次命中菸怪計為一次打擊；小菸怪 3 下擊敗。
- 菸怪被擊敗後通知 GameManager 增加淨化進度。
- BOSS 以血量計算傷害，近戰與噴霧的傷害值見第八章。

## 六、三階段流程與 NPC 故事事件

### 6.1 三階段總覽

| 階段 | 玩家要做的事 | 淨化進度 | 進入下一階段的條件 |
|---|---|---|---|
| 新手教學 | 依提示完成 4 個步驟 | 0% | 擊敗教學菸怪 |
| 第一階段｜持續打菸怪 | 在街上擊敗 5 隻小菸怪（新手教學的延續與緩衝） | 0 → 20% | 5 隻全部擊敗 → 觸發「NPC 跑來求救」 |
| 第二階段｜持續打怪＋了解被迫吸菸者的故事 | 完成三個 NPC 事件，並清除空檔出現的菸怪 | 20 → 60% | 三個事件完成 → 拿到藏寶圖 → 淨化達 60% 才能打開寶箱 → 拿到噴霧 → 第三階段 |
| 第三階段｜打 BOSS | 捏熄吸菸者的菸、閃避攻擊、打倒 BOSS | 60 → 100% | BOSS 血量歸零 → 結局動畫 → 勝利結算 |

### 6.2 階段轉換事件：NPC 跑來求救

第一階段的 5 隻菸怪全部擊敗後，第一位 NPC 跑來求救，畫面提示：「城市中還有很多需要幫助的人，快去看看吧！」，進入第二階段。

### 6.3 NPC 事件共通流程

1. NPC 跑到玩家身邊求救，以對話框說明請求。

2. 事件 1 為強制進行（和新手教學一樣沒有拒絕選項）；事件 2、3 會跳出「要幫忙嗎？」視窗，玩家可選擇幫忙或拒絕。

3. 選擇幫忙：畫面淡出，玩家與 NPC 一起傳送到故事地點（鏡頭固定，淡入淡出換場）。

4. 消滅故事地點周圍的 3 隻菸怪。

5. 聽被迫吸菸者的故事（對話）。

6. 靠近吸菸者按 E 觸發互動。

7. 播放故事結局：吸菸者決定不再讓身邊的人吸二手菸。

8. 最初求救的 NPC 給玩家道具，並在對話中說明這個戒菸資源的真實用途。

9. 傳送回街道。40 秒後下一位 NPC 跑來求救；空檔期間街上出現 2 隻菸怪，玩家需自行清除以提高淨化進度。

#### 拒絕幫忙時

- 拒絕後，整張地圖的菸怪都無法消除。
- 拒絕期間，所有菸怪的煙霧範圍每 10 秒擴大 10%，最多擴大到 2 倍【建議初始值】；玩家躲得再遠，最後也會吸到菸扣血。
- NPC 會跟隨玩家移動，玩家回頭找 NPC 按 E 即可重新接下任務；接下後煙霧範圍恢復原狀。
- 提示方式：不直接告訴玩家，讓玩家從「打不掉、煙越來越大」自己意識到要回去完成事件。

### 7.1 道具規格

- 背包顯示在畫面下方，列出持有的道具與數量。

- 滑鼠右鍵使用選取的道具；一次性道具使用後移除，噴霧保留。
- 背包為空時，右鍵沒有效果。

## 八、第三階段：BOSS 戰

### 8.1 BOSS 設定

BOSS 大煙怪是「剩下 40% 的二手菸匯聚而成的大煙怪」。BOSS 的血量對應剩下的淨化進度：淨化進度 = 60% + 40% ×（1 − BOSS 目前血量 ÷ 最大血量），打倒 BOSS 即淨化 100%。

### 8.2 登場流程

1. BOSS 出現動畫：大煙怪從吸菸室衝上天空，畫面亮出 BOSS 血條。

2. 原本在吸菸室裡的吸菸者往外跑、四處散開，在街上的固定位置抽菸。

3. 跳出「第三階段規則介紹視窗」，說明三個道具的用途、捏熄菸蒂的按鍵與 QTE、如何攻擊 BOSS；三個道具都已在背包中。

4. 玩家點擊後進入 BOSS 戰。

### 8.3 戰鬥機制：地面與天上

BOSS 每隔一段時間在「地面」與「天上」之間切換。

|  | BOSS 在地面 | BOSS 在天上 |
|---|---|---|
| 大煙怪 | 短暫下來休息（停留時間不長），同時對玩家吐小菸圈 | 自動回血；血量越少，飛得越低、體型越小；每隔一段時間朝玩家位置的地板吐菸炮（落地後留下一片煙霧區） |
| 玩家 | 閃避小菸圈；可近身攻擊 BOSS（但 BOSS 會回血） | 閃避菸圈與菸炮；衝去捏熄吸菸 NPC 的菸；可用噴霧遠程攻擊 BOSS（但 BOSS 會回血） |
| 吸菸 NPC | 散落在街上固定位置抽菸；菸被捏熄後不能再抽 | 同左 |

### 8.4 吸菸 NPC 與捏熄菸蒂

- 街上共 4 位吸菸 NPC：爸爸、北友會的兩位朋友、阿公（都是第二階段故事中的吸菸者）。
- 吸菸 NPC 是煙霧來源，靠近會增加暴露值。
- 捏熄方式（QTE 連打）：面向 NPC，在前方 90 度、2 公尺內按 E 開始 QTE，畫面顯示進度條；【建議】2 秒內連打 E 5 次即捏熄成功。
- QTE 失敗：【建議】進度歸零，可以立刻重新開始；QTE 期間 BOSS 照常攻擊，玩家要找安全的時機捏菸。
- BOSS 回血速度與「還在抽菸的人數」成正比：抽菸的人越多，回得越快。

### 8.5 最終局面

1. 所有吸菸者的菸都被捏熄後（開始近戰打 BOSS 的關鍵點），BOSS 永久停留在地面，不再回血。

2. BOSS 沒有煙可以噴了，改用物理攻擊玩家。

3. 玩家在 HP 歸零前打倒 BOSS。

4. 進入結局動畫：BOSS 留下遺言，鏡頭帶過全景綠色無煙城市。

5. 進入勝利結算。

### 8.6 BOSS 建議數值

| 項目 | 建議初始值【可調】 |
|---|---|
| BOSS 最大血量 | 150 |
| 玩家近戰傷害 | 每下 3 |
| 戒菸噴霧傷害 | 每下 7.5（冷卻 1.5 秒） |
| 地面停留時間 | 8 秒 |
| 小菸圈 | 地面時每 2 秒朝玩家吐 1 個；命中扣 8 HP |
| 天上停留時間 | 12 秒 |
| 菸炮 | 天上時每 4 秒 1 發，落點為玩家當下位置；直接命中扣 15 HP，落地後留下 3 秒煙霧區（煙霧來源） |
| 回血（地面） | 每位還在抽菸的 NPC 每秒 +1 HP |
| 回血（天上） | 每秒 +1 HP，再加上每位抽菸 NPC 每秒 +1 HP |
| 物理攻擊（菸全部捏熄後） | 玩家在 3 公尺內時每 3 秒揮擊一次，命中扣 10 HP |
| BOSS 煙霧半徑 | 7 公尺 |

※ 數值在最後測試階段再調整。測試重點：玩家不使用貼片時，能否在 HP 歸零前完成捏菸與擊敗 BOSS。

## 十、數值、勝敗與結算規則

### 10.1 主要數值

| 系統 | 規格 |
|---|---|
| 倒數計時 | 無；只記錄用時，暫停與過場動畫不計時 |
| HP | 100；暴露值 100 每秒 −5；BOSS 攻擊見 8.6 |
| 暴露值 | 0–100，畫面效果呈現；≥ 80 警示；100 扣血、咳嗽、減速 30% |
| 淨化進度 | 第一階段 20%、第二階段 +40%（共 60%）、BOSS +40%（共 100%） |

| NPC 事件間隔 | 每個事件結束後 40 秒，下一位 NPC 出現 |

| BOSS | 血量 150；其他見 8.6 |
| 結算評分 | 剩餘血量 60%、用時 40% |

### 10.2 勝敗條件

| 結果 | 觸發條件 | 系統回應 |
|---|---|---|
| 勝利 | 打倒 BOSS，淨化進度達 100% | 結局動畫 → 勝利結算 |
| 失敗 | HP 歸零（任何階段） | 停止遊戲，進入失敗結算 |

### 10.3 重新挑戰規則

- 第一、二階段失敗：結算畫面按「重新開始」，回到開場選擇。
- 第三階段失敗：結算畫面多一個「從第三階段重新挑戰」按鈕，從 BOSS 登場後重新開始。
- 重新挑戰時：
- 用時持續累計，不歸零。
- HP 恢復成「第一次進入第三階段時」的數值，道具恢復成進入第三階段時的狀態。
- 結算的血量分以最後一次成功打倒 BOSS 時的剩餘血量計算。

### 10.4 結算評分【建議初始值】

總分 = 血量分 × 60% ＋ 用時分 × 40%

| 項目 | 算法 | 備註 |
|---|---|---|
| 血量分 | 結算時 HP ÷ 100 × 100 | 血量反映吸入多少菸霧，權重較高 |
| 用時分 | 用時 ≤ 8 分鐘得 100；之後每多 30 秒 −10，最低 0 | 失敗局用時分為 0 |

| B | 70–79 | 街頭淨化員 |
| C | 60–69 | 菸霧見習生 |
| D | 0–59 | 還在咳嗽中 |
| 失敗 | — | 被菸霧吞沒（評級固定 D） |

## 十二、三人分工與 AI Vibecoding 協作

### 12.1 分工調整原則

## 十五、測試與驗收標準

### 15.2 遊戲平衡測試

- 新玩家是否能在約 8–10 分鐘內完成整局。
- 拒絕幫忙時，煙霧範圍擴大的速度是否讓玩家在合理時間內意識到要回去。
- BOSS 戰中，玩家不使用貼片時能否在 HP 歸零前完成。
- BOSS 回血速度是否讓「先捏菸蒂再打 BOSS」成為明顯的策略。
- 菸圈、菸炮的提示是否清楚到玩家能閃避。
- 畫面效果最強時是否仍能看清路線與目標。

## 十八、遊戲機制流程（文字版）

### 18.1 整體流程

1. 開始遊戲（主選單）→ 死巷 NPC 遞菸 → 接受或拒絕？

2. 接受（全部是動畫）→ 玩家吸菸 → 隨機一位路人受二手菸影響（咳嗽）→ 老奶奶／小朋友／爸爸教訓玩家 → 玩家暈倒 → 回到選擇的地方。

3. 拒絕 → 朋友點菸 → 新手教學（V 切換視角 → WASD 走出車庫 → 走到小菸怪旁 → 左鍵攻擊）→ 「消滅所有的煙怪吧！」

4. 第一階段｜持續打菸怪（5 隻，淨化 20%）→ NPC 跑來求救（階段轉換事件）。

5. 第二階段｜持續打怪＋了解被迫吸菸者的故事：事件一 → 40 秒 → 事件二 → 40 秒 → 事件三。

6. NPC 任務完成 → 老奶奶給藏寶圖 → 淨化達 60%？→ 否：寶箱鎖住並提示繼續消滅菸怪；是：吸菸室旁寶箱拿噴霧 → 第三階段動畫。

7. 第三階段｜打 BOSS → BOSS 從吸菸室衝上天、吸菸者散開 → 第三階段規則介紹視窗 → BOSS 戰。

8. 吸菸者的菸全部捏熄 → BOSS 永久停在地面、不回血、改用物理攻擊 → 在 HP 歸零前打倒 BOSS。

9. 結局動畫（BOSS 遺言、綠色無煙城市）→ 勝利結算 → 依數值顯示等第與頭銜。

### 18.2 全程機制

- 在煙霧範圍內暴露值上升，上升時畫面出現暗角並變灰；暴露值達 100 每秒扣血。
- 任何階段 HP ≤ 0 → 進入結算畫面（失敗）；第三階段失敗可從第三階段重新挑戰。
- 暫停選單（Esc）：繼續遊戲、重新開始、返回主選單。

### 18.3 NPC 事件流程

1. NPC 跑來求救 →（事件二、三）要幫忙嗎？

2. 不幫忙 → 整張地圖菸怪無法消除、煙霧範圍擴大 → 玩家需回去完成 NPC 事件，否則最終會因扣血而失敗。

3. 幫忙 → 傳送到故事地點 → 消滅菸怪 → 聽被迫吸菸的故事 → 按 E 互動 → 故事結局 → NPC 給道具（說明真實用途）→ 回到街道。

### 18.4 BOSS 戰流程

1. BOSS 在地面：短暫休息並吐小菸圈；玩家閃避並近身攻擊（BOSS 會回血）。

2. BOSS 在天上：自動回血、朝玩家吐菸炮，血越少飛越低、越小；玩家閃避、捏熄吸菸 NPC 的菸、用噴霧遠程攻擊。

3. 地面與天上每隔一段時間切換；吸菸 NPC 從吸菸室出來散落在街上抽菸，菸被捏熄就不能再抽。

4. 菸全部捏熄 → BOSS 永久停在地面、不再回血、改用物理攻擊 → 打倒 BOSS。
